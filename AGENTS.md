# AGENTS.md

## Project Context

This is the Fitaval Gym CRM application built with React, Vite, and Tailwind CSS.

## Key Files

- `src/`: frontend application source.
- `src/api/client.js`: persistent local client and storage layer.
- `vite.config.js`: Vite configuration.
- `package.json`: application scripts and dependencies.

## Working Notes

- Use `npm run dev` to start the local development server.
- Run `npm run build` to validate production builds.
