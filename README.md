# Fitaval - Gym Management CRM

A modern, responsive gym and fitness business management web application built with React, Vite, Tailwind CSS, and Lucide Icons.

## Features

- **Dashboard**: Real-time business overview, membership statistics (active, expiring, inactive), 7-day revenue trend area chart, today's income, and quick member registration actions.
- **Member Management**: Track members, contact details, assigned membership plans, renewal dates, and status filters.
- **Finance & Accounting**: Record and categorize income (memberships, personal training) and expenses (salaries, equipment, utilities) with interactive charts.
- **Membership Plans**: Configurable plans (duration, pricing, benefits, active toggles).
- **Trainers**: Manage certified personal trainers, bios, specializations, and profile photos.
- **Wallet**: Settlement management, transaction logs, withdrawal tracking, and balance summary.
- **Gym Profile**: Business branding, address, operating hours, amenities, and gallery showcase.

## Getting Started

### Prerequisites

Ensure you have Node.js (version 18 or newer) installed.

### Installation

```bash
npm install
```

### Running Locally

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
